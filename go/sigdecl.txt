# The call surface: one declaration line per built-in function
# (docs/design/SIGNATURES.0.md). THIS FILE IS THE SOURCE — both ports
# carry a build-time-inlined copy (ts/src/sigdecl.ts, go/sigdecl.txt;
# `make sig` regenerates both, and each port's suite asserts its copy
# is byte-identical with this file) and parse it at initialisation
# with the signature grammar, a tabnas grammar (ts/src/sig.ts,
# go/sig.go). The suites also round-trip every line:
# render(parse(line)) must be the line exactly, in both ports.
#
# The syntax (rendered TypeScript-ish, honest about argument MODES):
#   line = name '(' [ arg {',' arg} ] ')' ':' type
#   arg  = [mode] name ['?'] ':' type
#        | '...' name ':' '(' [mode] type {',' [mode] type} ')'
#   type = word {'|' word}
#   mode = 'capture' | 'template' | 'trial' | 'projector' | 'text'
# `value` mode is unmarked. `constraint` is the result word for
# residuals whose meet depends on the peer; `any` is the honest type
# where a function is a wrapper.
